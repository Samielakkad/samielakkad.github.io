darija-tools

I built a Python package and CLI for Arabic cleanup and Arabizi conversion.Tool

Python package · CLI

26/30 exact phrases on the v0.2 test set

The task

Arabizi spelling varies, and a character table alone cannot resolve every word. I wanted a small tool with inspectable rules and a result that could be checked.

What I built

I built text normalization, Arabizi conversion, loanword handling, a Python library, and a CLI. I versioned a 30-phrase set separately from the unit tests and published the evaluator and error report.

Result

The v0.2 report records 26/30 exact phrase matches (86.7%) and 61/66 exact whitespace-token matches (92.4%). This is a small, manually curated regression set. The four phrase errors remain visible, and the script can regenerate the report. The package is published on PyPI.
