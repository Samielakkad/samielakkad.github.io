# Sami El Akkad — AI Deployment & Product

Personal portfolio: [samielakkad.github.io](https://samielakkad.github.io/).

English and Arabic pages featuring selected work, a searchable catalog of 14 public projects, four awards, eight work and study entries, research notes, and direct contact links. Project descriptions distinguish personal ownership from team contributions and prototype results from production outcomes.

## Run locally

```sh
python3 -m http.server 8347 --bind 127.0.0.1
```

Open http://127.0.0.1:8347/. No install or build step is required.

## Files

- `index.html`, `index.ar.html`: English and Arabic portfolio.
- `assets/portfolio.css`: shared responsive design and reduced-motion styles.
- `assets/portfolio.js`: optional project filters, search, anchor expansion and Shenzhen clock.
- `thesis.html`: pre-rendered bachelor’s research write-up.
- `project-notes.html`, `project-notes.ar.html`: supporting project notes.
- `DESIGN.md`: implemented design system.
- `PRODUCT.md`: audience, content boundaries and product constraints.
- `assets/PROVENANCE.md`: image and font origins.

Native disclosure controls, content, navigation and contact links work with JavaScript disabled. Filters appear only when JavaScript is available. Fonts and images are served locally.

## Validation

The November 2026 rebuild was checked in Chromium at phone, tablet and desktop sizes, including Arabic RTL, 320px layout, expanded content, keyboard controls, project deep links, reduced motion and JavaScript-disabled browsing. Automated accessibility checks are useful coverage, not a guarantee of complete accessibility.
